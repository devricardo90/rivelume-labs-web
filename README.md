# Rivelume Labs

Repositório do website institucional e comercial B2B da Rivelume Labs. Esta execução prepara a governança da Sprint 0; o website ainda não foi iniciado.

## Estado atual

- A Fonte da Verdade foi localizada e lida. É a versão 0.1, em rascunho, aguardando aprovação do Owner.
- O projeto Jira RIV ainda não existe na instância conectada.
- A branch `governance/sprint-0-foundation` foi publicada com o commit inicial de governança. O repositório não tem ref `main`, então o PR ainda não pode ser aberto.
- A stack técnica permanece proposta, sem aprovação.

## Instruções iniciais

1. Leia `AGENTS.md` e `docs/GOVERNANCE.md`.
2. Confirme que a Fonte da Verdade está aprovada antes de executar qualquer trabalho de produto.
3. Aguarde a criação e verificação do projeto Jira RIV antes de selecionar tarefas.
4. Não instale stack nem inicie a implementação até aprovação dos gates da Sprint 0.

Nenhuma stack está aprovada. Next.js, TypeScript, Tailwind CSS e hospedagem Vercel constam somente como propostas no documento canônico.
