# Contexto do projeto

## Identidade e objetivo

Rivelume Labs é um estúdio independente de tecnologia B2B. Este repositório é destinado ao website institucional e comercial que apresenta desenvolvimento de software, automação empresarial e soluções práticas de inteligência artificial. Mercados: Brasil e Europa. Idiomas: inglês e português brasileiro.

O documento canônico é a [Fonte da Verdade — Rivelume Labs](https://docs.google.com/document/d/1hfrUEnS6E12huzGAPq7sFH00rKnBqny0tD5BnUqGlmo/edit), ID `1hfrUEnS6E12huzGAPq7sFH00rKnBqny0tD5BnUqGlmo`, versão 1.0, aprovada pelo Owner em 11/10/2026. Este arquivo resume apenas o contexto técnico e operacional; não replica o PRD.

## Escopo inicial

Website comercial B2B institucional. A Fonte da Verdade mantém decisões de página, proposta de valor, contato, identidade visual, domínio/e-mail e portfólio como propostas ou pendências quando assim identificadas. A aprovação V1.0 não as aprova implicitamente. Não iniciar funcionalidade associada a decisão pendente até decisão explícita do Owner.

Está explicitamente fora de escopo sem requisito aprovado: SaaS, autenticação, dashboard, banco de dados, CMS complexo e backend. O conteúdo de projetos públicos depende de auditoria e aprovação.

## Stack aprovada

Para o website comercial B2B inicial: Next.js, TypeScript, Tailwind CSS e Vercel, conforme decisão do Owner e DEC-RIV-006 da Fonte da Verdade. Essa aprovação não aprova qualquer infraestrutura de produção, implantação ou serviço pago nesta etapa.
